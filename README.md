# The Guide to a13i

**a13i** (say it "ay thirteen eye") is a numeronym for **Accessibility AI**: the letter a, thirteen letters, the letter i. It belongs to the same family as a11y (accessibility) and i18n (internationalization).

> Count it: `a` + `ccessibility a` (13 letters) + `i`

This repository is an open book and an open corpus. It documents how AI systems and accessible interfaces interact, what we can measure about that interaction, and how developers can build for humans and machines at the same time.

Live site: https://a13i.org

## The one-sentence thesis

Interfaces that work for assistive technology tend to work for AI agents, and the reverse is increasingly true, so accessibility and machine readability should be engineered, measured, and advocated as one discipline.
