# 001: Name and positioning

- **Status:** accepted (collision check completed 2026-06-10, verdict: minor collisions, clear to proceed)
- **Date:** 2026-06-10

## Context

The project needs a name that claims the category of AI-and-accessibility before others do, reads instantly to web developers, and signals respect for the a11y tradition rather than appropriation of it.

## Decision

The name is **a13i**, numeronym for Accessibility AI (`a` + 13 letters + `i`), domain a13i.org. The project is an open book plus an open experiment corpus plus, as it grows, a consortium.

Positioning guardrails, binding on all public material:

1. a13i lifts a11y and never replaces it. The manifesto's people-first rule (section 4) is the project's identity, partly because the a11y community has well-earned hostility toward AI products that promised accessibility and delivered overlays.
2. No claims without corpus backing. Unproven statements are labeled hypotheses, including in marketing.
3. Founder and The Blind Computer are presented as practitioners publishing evidence, in the voice of a sighted ally of blind users, never in a voice that claims disabled people's experience.

## Collision check results (2026-06-10)

- The exact string "a13i" is unclaimed as an accessibility or AI coinage. No GitHub user or repo, no defined public meaning.
- One adjacent personal use exists: an AI-in-healthcare writer using a13i as a personal handle (a13i.substack.com, tasks.a13i.dev), derived from his own name, with no claim on "Accessibility AI". SEO contention is possible; conceptual collision is not.
- Unrelated industrial part numbers (an antibody clone, an injector adaptor, a gas sensor) share the string in other sectors.
- Action items before launch: register the a13i handle on X, GitHub (org), Bluesky, and Mastodon; expect and plan for a11y/a13i confusion in copy.

See `docs/research/landscape-2026-06.md` for the full prior-art landscape.

## Consequences

- Verdict is minor collisions, so this record stands and launch may proceed.
- The name is held in trust for the project per GOVERNANCE.md.
- Public positioning is "synthesize and extend" rather than "discover": the core finding already exists in published literature (see landscape report) and a13i leads by citing it.
